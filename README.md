# Plugou Artes

Portal de revendedores da Plugou. Next.js + Supabase.

O projeto usa armazenamento privado, autenticacao no Supabase e uma funcao administrativa protegida.

## Configuracao

Configure em Vercel `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.

Repositorio de codigo, sem senhas ou chaves secretas.
